# Carnivorus 1.2 strength pass (2026-11-15)

Engine baseline: `d4c44365fe236e56299a532321214af5525dd650` (1.1).
Engine candidate: 1.2 (this branch).
All engine changes are original C. No external engine code or weights were copied.
The evaluation weights were tuned by Texel's method on positions from Carnivorus
self-play games only. Stockfish was used only as a separate test opponent and
opening generator. No spending was added. NNUE, book and tablebase dependencies:
none.

## Changes retained

- Evaluation rewritten as explicit sparse features over 512 mg + 512 eg weights
  (verified score-identical to 1.1 before tuning), enabling Texel tuning of the
  engine's own handcrafted terms.
- Texel tuning, three rounds, self-play data only:
  round 1 on 131k positions (validation loss 0.0946 -> 0.0935),
  round 2 on 294k positions (0.0918, K ~= 0.92),
  round 3 on 469k positions (0.09285 -> 0.09261 on the larger set).
  Each round's data was generated by the previously tuned engine.
- Lazy SMP: `Threads` UCI option (1-32, default 1), shared lockless transposition
  table (key^data packing), per-thread search state. A tuning-dump race that
  poisoned evaluation under threads was found and fixed during testing.
- Singular extensions (added after the first 1.2 validation): when the TT move
  at a non-root node with depth >= 8 has a sufficiently deep exact/lower-bound
  entry, the position is searched with that move excluded at reduced depth; if
  all alternatives fail below tt_score - 2*depth, the TT move is extended one
  ply. Screened at +40 Elo [+3, +77] over 238 games at 35 ms/move against the
  pre-SE build; neutral at fixed nodes, as expected.
- Version string is 1.2.

Discarded after 224-game screens (nodes=8000) against the tuned build: earlier
LMR (-30 Elo), more aggressive late-move pruning (+6), smaller reverse-futility
margin (-12), tighter aspiration delta (+11). The existing search constants were
left unchanged; none of the screened alternatives showed a measured win.

## Validation

GCC `-O2 -Wall -Wextra -std=gnu11 -pthread`: no warnings.
`make test`: all perft positions pass, plus the exchange/cache/draw/TT
white-box regressions. `python3 tests/uci_smoke.py`: legal PV and bestmove,
stop, movetime and short-clock checks pass.

## 1.2 versus 1.1 matches

Both engines: 32 MiB hash, one thread, Move Overhead 0, same build flags.
Two games concurrently on a two-vCPU host, alternating colours, saved openings
from `tests/validation_openings.json` (seed 20261115). Node-limited games are
deterministic per opening, so the 256-opening set caps node-match size;
time-control matches are not capped this way.

| Match | Games | 1.2 W/D/L | 1.2 score | Implied Elo difference |
| --- | ---: | --- | ---: | ---: |
| nodes=8000 per move | 256 | 126/61/69 | 61.13% | +79 |
| 35 ms/move | 126 | 45/47/34 | 54.37% | +30 |

Approximate 95% intervals over opening-pair scores (descriptive, not SPRT):
+41 to +119 and -16 to +78 Elo. These final matches include singular
extensions; the pre-SE build measured +67 [+29, +108] and +63 [+19, +110]
on the same setup, and the SE-versus-pre-SE difference itself screened at
+40 [+3, +77], so the build is at least as strong as the pre-SE numbers. The direction of improvement is consistent
across both conditions; the size can change with opponents, openings, hardware
and time control.

SMP check (1.2 with Threads=2 versus Threads=1, 74 games at 35 ms/move):
55.4% score, about +38 Elo with a wide interval; 2 threads gave 1.38x nodes.
Threads=1 remains the default.

## Approximate absolute rating

Stockfish 14.1 Ubuntu binary, one thread, 32 MiB hash, UCI_LimitStrength true,
Use NNUE false, 100 ms/move, alternating colours, same saved openings:

| Stockfish UCI_Elo | Games | Carnivorus 1.2 W/D/L | Score | Setting plus implied difference |
| --- | ---: | --- | ---: | ---: |
| 2200 | 32 | 16/4/12 | 56.25% | 2244 |
| 2300 | 32 | 12/8/12 | 50.00% | 2300 |
| 2400 | 48 | 10/12/26 | 33.33% | 2280 |

For comparison, the 1.1 baseline measured with this protocol scored 50.00%
at the 2200 setting, 48.44% at 2300 and 35.42% at 2400.

**Approximate rating: around 2300 on this limited-strength test scale**, with a
rough practical uncertainty range of 2150-2450. This is not FIDE, CCRL or CEGT
Elo. These are ultra-fast games, Stockfish's setting is not an absolute
calibrated rating at this time control, and its weakening is not transitive:
one intermediate build scored 73% against the 2200 setting while scoring worse
than 1.1 at the 2300 setting. The direct 1.2-versus-1.1 matches above are the
reliable evidence of improvement; this calibration only anchors the rough level.
